## 🚀 How to Run Locally

1. **No Node.js or build steps required!**
2. Double-click **`index.html`** in your browser (Chrome / Edge / Firefox).
3. Enter Security PIN: **`2026`**.
4. Enjoy real-time 6-second live streaming telemetry across 12 major Indian cities.

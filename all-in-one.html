Akansha's 30-Second SIH Judge Pitch (Database & Storage Lead)

"Hello Judges! I designed and built the Database Architecture and Data Management Layer (Layer 2). I developed the 3NF relational SQLite schema to ingest, index, and organize live telemetry across 12 Indian districts. My architecture features sub-millisecond B-Tree queries, foreign-key data integrity, and time-series partitioning. This ensures that Bhavishya's data processing, Deep's AI forecasting pipeline, and Saurav's live frontend visualisations receive reliable, lightning-fast data streams without any bottleneck."

Judge Q: "Why SQLite for Hackathon MVP & how will it scale?"

"SQLite in WAL mode provides zero-configuration, lightning speed, and serverless reliability for local demo nodes. Our schema strictly follows ANSI-SQL standards, allowing a 1-click migration to PostgreSQL or TimescaleDB for multi-state production deployments."

Judge Q: "How does your DB handle missing sensor packets?"

"We implement database-level check constraints and fallback triggers that route null readings to Layer 3 (Bhavishya's Python pipeline) for KNN interpolation before AI scoring."
